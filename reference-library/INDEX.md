# 设计参考资料库总索引

## 1. 资料库用途

本索引用于统一管理建筑设计、室内设计、景观设计及软装陈设相关的模型、图纸、图片和案例资料。

通过分类、关键词和文件路径，实现资料的快速检索、复用与持续积累。
