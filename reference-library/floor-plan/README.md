# Floor Plan Visual Reference Library
# 平面图视觉标准图库


## Purpose（目的）

This library defines the visual presentation standards for architectural floor plan drawings.

本图库用于定义建筑平面图的视觉表达标准。


The purpose is to maintain consistent graphic language across all generated floor plans.

用于保证所有生成平面图具有统一的制图语言和展示标准。



---

# Reference Usage（参考使用规则）


Reference images must not be interpreted as project-specific drawings.

参考图片不得被理解为当前项目建筑图。

They do not define:

不定义：


- Architectural layout（建筑布局）
- Room location（房间位置）
- Spatial dimensions（空间尺寸）
- Functional relationships（空间功能关系）


All architectural decisions must follow the original project drawings.

所有建筑空间决策必须遵循原始项目平面图。

# Generation Rules（生成规则）


When generating floor plans:

生成平面图时：


1. Follow the reference graphic language.

   遵循参考图的视觉语言。


2. Maintain black and white architectural drawing style.

   保持黑白建筑制图风格。


3. Keep wall and furniture representation consistent.

   保持墙体及家具表达一致。


4. Follow annotation and layout standards.

   遵循文字标注和版式标准。


5. Do not copy architectural layouts from reference images.

   不复制参考图片中的建筑布局。
