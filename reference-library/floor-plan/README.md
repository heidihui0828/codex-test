
# Floor Plan Visual Reference Library
# 平面图视觉标准图库


## Purpose（目的）

This library defines the visual standards for architectural floor plan presentation.

本图库用于定义建筑平面图方案展示的视觉标准。


## Reference Images（参考图片）


### floor-plan-style-reference-01

Defines:

- Black and white architectural drawing style.
- Wall line thickness hierarchy.
- Furniture line drawing language.

定义：

- 黑白建筑制图风格；
- 墙体线条粗细关系；
- 家具线稿表达方式。


### floor-plan-style-reference-02

Defines:

- Presentation layout.
- Annotation placement.
- Professional design board composition.

定义：

- 方案展示排版；
- 文字标注布局；
- 专业设计方案构图方式。


## Usage Rules（使用规则）

The reference images define graphic style only.

参考图片只定义绘图表现方式。


They do not define architectural layout.

不定义建筑空间布局。


All generated floor plans should follow this visual language.
所有生成的平面图应遵循该视觉标准。
