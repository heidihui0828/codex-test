# 平面参考资料库

## 一、用途

本目录用于收集、整理和检索建筑及室内设计相关的平面参考资料，例如户型图、功能布局、案例图纸和空间组织参考。

参考资料主要用于分析和启发设计，不应未经核对直接作为施工图或正式设计成果使用。

## 二、建议分类

可根据资料数量逐步建立以下子目录：

- `住宅/`：公寓、住宅、别墅等平面案例。
- `商业/`：办公室、零售店铺及其他商业空间。
- `酒店餐饮/`：酒店客房、餐厅、咖啡馆等案例。
- `公共空间/`：公共建筑和共享空间案例。
- `空间模块/`：厨房、卫生间、楼梯、走廊等局部布局参考。
- `待整理/`：暂时无法确定分类的资料。

不需要一次性创建所有目录；有实际资料时再建立即可。

## 三、文件命名

建议采用以下格式：

`类别_空间类型_主要特征_来源或编号.文件格式`

示例：

- `住宅_两居室_紧凑户型_REF001.pdf`
- `商业_办公室_开放式布局_REF002.jpg`
- `空间模块_卫生间_无障碍布局_REF003.png`

文件名应简洁、明确。若原始文件名包含重要的项目编号或来源信息，应在整理时保留这些信息。

## 四、资料记录

每份参考资料尽可能记录：

| 字段 | 内容 |
|---|---|
| 资料编号 | 唯一编号，例如 REF001 |
| 资料名称 | 简洁描述图纸或案例 |
| 分类 | 住宅、商业、空间模块等 |
| 空间类型 | 客厅、厨房、办公室等 |
| 关键特点 | 布局、动线、功能组织等 |
| 尺寸与单位 | 仅记录图纸明确提供或已核实的数据 |
| 来源 | 原始项目、出版物或网页链接 |
| 文件路径 | 资料在仓库中的相对路径 |
| 使用限制 | 版权、授权或保密要求 |
| 备注 | 其他说明 |

不确定的信息应标记为“待核实”，不要根据图片外观猜测准确尺寸。

## 五、收录流程

1. 保存原始资料及其来源信息。
2. 判断资料所属类别和参考价值。
3. 检查版权、授权和项目保密要求。
4. 使用统一命名规则整理文件。
5. 将资料放入合适的分类目录。
6. 更新资料索引，记录文件路径和关键特点。
7. 检查文件是否能正常打开、预览。

对于客户项目资料，应优先保存在对应项目目录中。只有在获得适当授权、完成必要脱敏并确认具有复用价值后，才将副本收录到通用参考库。

## 六、参考资料与模型的区别

- **reference/**：保存案例图纸、图片、研究资料及设计参考。
- **Model/**：保存经过整理、可供后续项目复用的模型或空间模块。

参考资料不一定适合直接复用；如需转化为模型，应重新核对尺寸、功能、适用条件和使用权限。

## 七、检索方法

查找资料时，优先根据以下条件筛选：

1. 空间类型和使用功能。
2. 大致尺寸及面积范围。
3. 布局特点和交通动线。
4. 项目类型及适用条件。
5. 文件格式和来源可靠性。

向 AI 请求检索时，可描述空间用途、尺寸范围、功能需求和希望参考的特点。检索结果应包含资料名称、文件路径、来源及相关限制；若未找到匹配资料，应明确说明，不得虚构库内文件。

## 八、版权与质量

- 记录资料来源，不将他人作品误认为原创成果。
- 未经授权，不公开发布受版权限制或涉及保密的资料。
- 保留原始资料，不随意覆盖或篡改。
- 区分已核实的数据与仅供参考的视觉判断。
- 定期清理重复文件，并检查链接是否有效。

## 九、后续完善

资料数量增加后，可建立统一索引表，并为重要资料添加预览图、关键词和适用条件。先确保来源清楚、分类合理、路径准确，再逐步增加自动化检索能力。
