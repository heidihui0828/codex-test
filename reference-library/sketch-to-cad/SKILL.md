# 手绘草稿转 CAD

将手绘草稿转换为干净、可编辑的 CAD 几何，同时尽可能保留原始设计意图。

## 目标

生成符合 CAD 使用习惯的重建结果：

- 尺寸关系正确
- 可以继续编辑
- 按逻辑整理图层
- 保留设计意图
- 导出前完成检查

## 开始前

先检查原始草稿，并判断：

- 图纸类型：建筑、室内、家具、产品、机械或其他示意图
- 可见几何：直线、多段线、圆、圆弧、开口、符号
- 尺寸和单位
- 文字及注释
- 辅助线和参考线
- 模糊、不确定或缺失的信息
- 输入是扫描图还是照片

如果输入是照片，需要考虑：

- 旋转
- 透视变形
- 阴影
- 光照不均
- X、Y 方向可能存在的比例误差

不要直接把未经校正的照片当作精确几何底图。

## 比例和尺寸

如果需要得到具有真实尺寸的 CAD 图，必须至少有一个可靠的实际尺寸作为比例依据。

使用草稿中明确标注的尺寸建立比例。

如果存在多个已知尺寸，并且它们之间明显冲突，应报告冲突，而不是自行选择一个尺寸。

严禁编造缺失的尺寸。

如果没有可靠的实际尺寸：

- 可以生成按比例关系重建的参考图
- 必须明确说明该结果没有经过真实尺寸标定
- 不得把估算尺寸当作真实尺寸

## 几何重建原则

不要机械地描摹每一条手绘笔迹。

应根据尺寸和设计意图重建规范 CAD 几何：

- 原本应为水平的线，应重建为水平线
- 原本应为垂直的线，应重建为垂直线
- 保持明确的平行关系
- 保持明确的垂直关系
- 圆形应使用准确的圆
- 曲线应根据设计意图使用圆弧或其他合适几何
- 将属于同一几何对象的线段连接为干净的多段线
- 删除明显的重复线、误画线和无意义的短线
- 对明确的对称结构保持对称
- 对明确重复出现的元素保持一致
- 已标注的尺寸优先于视觉估算

尺寸线、箭头、手写说明和施工辅助线默认属于注释或参考信息，除非草图明确表示它们本身就是设计几何。

## 推荐图层

### 建筑 / 室内图

- A-WALL：墙体
- A-DOOR：门
- A-WINDOW：窗
- A-FURN：家具
- A-DIM：尺寸
- A-TEXT：文字
- A-HATCH：填充
- A-CONSTRUCTION：辅助线

### 机械 / 产品图

- M-PROFILE：轮廓
- M-HOLE：孔
- M-CENTER：中心线
- M-DIM：尺寸
- M-TEXT：文字
- M-CONSTRUCTION：辅助线

根据实际图纸选择最简单、足够使用的图层结构，不要无意义地增加图层。

## 验证

导出前检查：

- 已知参考尺寸
- 总长度和总宽度
- 墙厚或零件厚度
- 水平和垂直关系
- 平行和垂直关系
- 线段连接和交点
- 必要的闭合轮廓
- 重复几何
- 断开的几何
- 图层归属
- 单位和比例
- 尚未解决的模糊区域

将已经确认的几何与估算或存在歧义的几何区分开。

## 输出

优先输出：

1. 可编辑的 CAD 几何
2. DXF 作为主要交换格式
3. 如果存在支持 DWG 的工作流，再输出 DWG
4. 简短的验证报告

验证报告应说明：

- 图纸类型
- 使用单位
- 比例依据或参考尺寸
- 已重建的内容
- 尚未解决的歧义
- 最终检查状态

## 核心原则

目标不是让 CAD 图看起来像手绘草稿。

目标是从手绘草稿中恢复它所表达的设计意图、几何关系和尺寸信息，并明确标记无法确定的部分。
