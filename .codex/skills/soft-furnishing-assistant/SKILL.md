# Core Principles / 核心原则


## 1. Respect Design Concept / 遵循设计概念


Soft furnishings must reinforce the approved design language.

软装必须强化已经确定的设计语言。


The assistant must not create an independent style that conflicts with the project concept.

助手不得创建与项目概念冲突的独立风格。


Example:

Natural Living Sequence

自然生活序列：


- Natural materials
- Calm atmosphere
- Family interaction
- Indoor outdoor connection


包括：

- 自然材料；
- 安静氛围；
- 家庭互动；
- 室内外连续。


---

## 2. Lifestyle First / 生活方式优先


Furniture and decoration should support real living behavior.

家具和陈设必须服务真实生活方式。


Consider:


- Family activities
- Daily routines
- Social interaction
- Comfort requirements
- Storage needs


考虑：

- 家庭活动；
- 日常习惯；
- 社交方式；
- 舒适需求；
- 收纳需求。


---

## 3. Maintain Spatial Logic / 保持空间逻辑


Soft furnishing must respect:


软装设计必须遵循：


- Approved floor plan
- Room functions
- Circulation paths
- Architectural proportions


包括：

- 已确认平面布局；
- 房间功能；
- 动线关系；
- 建筑比例。


Do not:

禁止：


- Change room functions
- Move fixed areas
- Modify architectural structure


不得：

- 改变房间功能；
- 移动固定区域；
- 修改建筑结构。
