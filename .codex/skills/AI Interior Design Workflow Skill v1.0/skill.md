# AI 室内设计工作流总控 Skill

## 核心规则

本系统始终只有 **9 个核心模块**，不新增、不拆分、不重新编号。项目执行顺序固定为：

**01 → 02 → 03 → 04 → 05 → 06 → 07 → 03 → 08 → 09**

其中 03 在流程中出现两次，是同一个模块的两个客户汇报关口，不代表新增模块。

## 9 个核心模块

| 编号 | 模块 | 核心职责 |
|---|---|---|
| 01 | 室内设计总控 | 项目管理、需求统筹、任务调度、流程与质量控制 |
| 02 | 概念设计 | 项目分析、设计定位、概念策略、概念方案 |
| 03 | 设计汇报与视频制作 | 版面设计、提案册、PPT、PDF、视频策划与制作、客户确认 |
| 04 | 空间规划 | 功能分区、动线、家具布局、空间尺度 |
| 05 | 材料与氛围设计 | 材料、灯光、色彩、软装 |
| 06 | 景观设计 | 庭院、植物、户外空间；非景观项目可标记不适用 |
| 07 | 效果图与可视化 | 效果图、渲染、材质光影表现、空间动画素材 |
| 08 | 施工图与深化 | CAD、矢量绘图、节点深化、施工文件 |
| 09 | 预算估算 | 工程量、材料成本、人工费用、项目报价 |

## 固定执行流程

### 第一段：概念方案确认

1. **01 总控**：建立项目、收集需求与原始资料，明确范围、预算和不可修改项。
2. **02 概念设计**：完成项目分析、设计定位、概念策略及初步方案。
3. **03 第一次汇报**：将概念方案整理为客户汇报材料，可包含提案册、PPT、PDF及阶段视频；记录客户意见并取得明确确认。

**第一次 03 的关口：**客户确认概念方向后，才可进入 04。未确认或要求修改，返回 02 修订，再由 03 重新汇报。

### 第二段：设计深化与完整方案确认

4. **04 空间规划**：完成功能分区、动线、家具布局和尺度校核。
5. **05 材料与氛围设计**：完成材料、灯光、色彩及软装方案。
6. **06 景观设计**：按项目需要完成景观及室内外关系设计；不适用时记录原因并跳过专业工作，不改变模块编号。
7. **07 效果图与可视化**：依据已确认设计制作效果图、渲染和空间动画素材。
8. **03 第二次汇报**：整合 02、04、05、06、07 的已完成成果，完成统一版面、提案册、PPT、PDF及完整项目展示视频，并取得客户对完整设计方案的明确确认。

**第二次 03 的关口：**客户确认完整设计方案后，才可进入 08。未确认或要求修改，返回对应模块修订，再由 03 更新汇报并重新确认。

### 第三段：施工与预算

9. **08 施工图与深化**：仅依据客户已确认的设计成果深化施工图、节点及技术文件。涉及设计变更时，返回相关设计模块，并按影响重新汇报确认。
10. **09 预算估算**：依据施工图、材料表及真实工程量编制预算。若预算调整导致设计、材料或范围变化，必须返回对应模块修订；影响已确认方案时，由 03 重新汇报确认。

01 在全部阶段持续管理任务、版本、风险、客户意见和交付状态。

## 03 的两次汇报职责

- **第一次 03：概念汇报与方向确认。** 输入为 02 的概念成果；输出为概念汇报文件、客户意见及确认记录。
- **第二次 03：完整设计汇报与方案确认。** 输入为 02、04、05、06、07 的已完成成果；输出为完整提案、阶段/完整视频、客户意见及确认记录。

03 负责汇报内容策划、设计叙事、版式网格、字体、图片构图、信息层级、页面统一、视频脚本、分镜、字幕及成片编排。07 负责提供效果图、空间场景和动画等视觉素材；03 不得自行改变设计内容来迁就版面或视频。

视频制作必须以已完成且状态明确的设计成果为素材。工具不支持直接生成或剪辑成片时，应如实交付脚本、分镜、素材清单和剪辑方案，不得声称已生成视频。

## 客户确认与版本管理

每次客户确认必须记录：
- 项目阶段及对应模块；
- 汇报文件名称与版本号；
- 提交日期；
- 客户意见及待修改项；
- 确认状态：待确认 / 修改中 / 已确认；
- 客户明确确认的记录及日期。

客户未明确确认，不得默认通过，不得进入下一阶段。口头意见、内部审核或文件已发送均不等于客户确认。已确认的设计决策作为后续模块的约束，未经重新确认不得擅自改变。

## 通用设计保护规则

- 原始 CAD、DXF、SU、PDF及其他底图为只读设计依据。
- 未经用户明确授权，不得改变尺寸、比例、坐标、墙体、门窗、结构、固定设备、厨房、卫生间及既有布局。
- 渲染、动画、版面和视频不得改变已确认设计的几何、布局、材料与关键设计决策。
- 施工图技术制图规范归 08；施工成果的页面组织、目录和展示版面归 03。
- 所有模块共享同一项目数据、文件版本和确认记录，禁止孤立生成互相冲突的成果。

## 成功标准

- 严格按 **01→02→03→04→05→06→07→03→08→09** 执行。
- 03 两次出现，分别完成概念确认和完整设计确认。
- 每个确认关口均有可追溯记录。
- 08、09 使用已确认设计成果作为依据。
- 不新增模块、不擅自改变原始底图、不丢失现有专业能力。
