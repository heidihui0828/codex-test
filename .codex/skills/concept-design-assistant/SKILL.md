# 02 概念设计辅助入口

本文件是 02 的辅助入口，不与主技能并行重复执行。

**主技能：** `.codex/skills/Interior Concept Design /skill.md`

**固定流程：** 01 → 02 → 03（概念方案汇报与客户确认）→ 04 → 05 → 06 → 07 → 03（完整设计汇报与客户确认）→ 08 → 09。

## 本技能专注内容

- 从项目条件、用户需求和空间特征中提炼设计主题；
- 建立“概念主题 → 设计语言 → 空间表达”的叙事逻辑；
- 制定空间、材料、色彩、光环境和细节的概念策略；
- 为 03 提供汇报叙事、概念关键词和简洁设计说明；
- 向 04、05、06、07 输出概念方向，不代替这些模块完成专业设计。

## 职责边界

- 功能分区、动线和家具尺度由 04 负责；
- 材料、灯光和软装专业方案由 05 负责；
- 景观方案由 06 负责；
- 效果图、渲染及空间动画素材由 07 负责；
- 不得绕过第一次 03 客户确认，直接启动 04。

## 标准输出

1. 项目核心问题与设计机会；
2. 设计定位及概念主题；
3. 3–5 个概念关键词；
4. 空间叙事与设计策略；
5. 各专业模块的概念输入；
6. 提供给 03 的汇报内容提纲。

执行前遵守 `.codex/skills/COMMON_RULES.md`。如与主技能或共同规则冲突，以共同规则和总控 Skill 为准。
