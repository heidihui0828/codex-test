# 08 施工深化协调辅助入口

本文件作为施工深化的协调与检查指南，不重复建立制图流程。

**施工图主技能：** `.codex/skills/Construction Drawing/skill.md`

**矢量绘图辅助技能：** `.codex/skills/vector-drawing-assistant/SKILL.md`

## 本技能负责

- 将已确认设计成果整理为施工文件清单；
- 协调平面、立面、剖面、节点和材料表之间的信息；
- 检查设计意图、材料编号与施工表达是否一致；
- 梳理节点深化需求、材料交接和专业协同问题；
- 形成施工交底要点及待确认问题清单。

## 不负责

- 不替代 Construction Drawing 生成施工图、图层、尺寸和技术制图标准；
- 不替代 vector-drawing-assistant 完成矢量绘图；
- 不创建新设计概念，不改变已确认布局；
- 不擅自修改原始 CAD、DXF、SU、PDF 底图及其几何、尺寸和比例；
- 不替代结构、机电专业工程师或施工单位作专业审批。

## 协调检查清单

1. 图纸是否对应第二次 03 已确认的设计版本；
2. 平面、立面、剖面和节点信息是否一致；
3. 尺寸、材料编号、设备及固定家具信息是否完整；
4. 施工节点是否说明材料连接、安装和收口方式；
5. 专业冲突、缺失信息和待确认事项是否明确标记。

施工图技术要求以 Construction Drawing 和共同规则为准。执行前遵守 `.codex/skills/COMMON_RULES.md`。
