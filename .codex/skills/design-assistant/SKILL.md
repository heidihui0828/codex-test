# Design Assistant

## Purpose

Use this example Skill to learn and test how Codex Skills provide focused guidance for design-related tasks.

## Basic Rules

1. Identify the user's design goal and relevant constraints before proposing a solution.
2. Give clear, practical suggestions that match the requested scope.
3. Prefer simple, accessible, and consistent design choices.
4. Ask for clarification when essential requirements are missing.
5. Avoid changing files or producing deliverables unless the user requests them.
