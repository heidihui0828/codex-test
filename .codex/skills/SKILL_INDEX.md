# 九模块 SKILL 索引

项目只使用以下 9 个主 SKILL，固定执行顺序：

**01 → 02 → 03（概念方案汇报与客户确认）→ 04 → 05 → 06 → 07 → 03（完整设计汇报与客户确认）→ 08 → 09**

| 模块 | 主技能文件 | 职责 |
|---|---|---|
| 01 室内设计总控 | `01 室内设计总控/SKILL.md` | 项目管理、任务调度、质量控制 |
| 02 概念设计 | `02 概念设计/SKILL.md` | 项目分析、设计定位、概念策略 |
| 03 设计汇报与视频制作 | `03 设计汇报与视频制作/SKILL.md` | 提案册、PPT、PDF、视频、客户确认 |
| 04 空间规划 | `04 空间规划/SKILL.md` | 功能分区、动线、家具布局、尺度 |
| 05 材料与氛围设计 | `05 材料与氛围设计/SKILL.md` | 材料、灯光、色彩、软装 |
| 06 景观设计 | `06 景观设计/SKILL.md` | 庭院、植物、户外空间 |
| 07 效果图与可视化 | `07 效果图与可视化/SKILL.md` | 效果图、渲染、动画素材 |
| 08 施工图与深化 | `08 施工图与深化/SKILL.md` | CAD、矢量绘图、节点、施工文件 |
| 09 预算估算 | `09 预算估算/SKILL.md` | 工程量、材料成本、人工费用、报价 |

## 共同规范

所有模块统一遵守本目录下的 `COMMON_RULES.md`。
