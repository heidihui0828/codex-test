# 九模块 SKILL 索引

项目只使用以下 9 个模块主 SKILL，按固定顺序执行：

**01 → 02 → 03（第一次客户确认）→ 04 → 05 → 06 → 07 → 03（第二次客户确认）→ 08 → 09**

| 模块 | 职责 | 主 SKILL |
|---|---|---|
| 01 室内设计总控 | 项目管理、任务调度、版本与质量控制 | `AI Interior Design Workflow Skill v1.0/skill.md` |
| 02 概念设计 | 项目分析、设计定位、概念策略 | `Interior Concept Design /skill.md` |
| 03 设计汇报与视频制作 | 提案册、PPT、PDF、视频、客户确认 | `presentation-assistant /SKILL.md` |
| 04 空间规划 | 功能分区、动线、家具布局、尺度 | `space-planning-assistant/SKILL.md` |
| 05 材料与氛围设计 | 材料、灯光、色彩、软装 | `material-selection-assistant/SKILL.md` |
| 06 景观设计 | 庭院、植物、户外空间 | `landscape-design-assistant/SKILL.md` |
| 07 效果图与可视化 | 渲染、效果图、空间动画素材 | `Render Generation /Skill .md` |
| 08 施工图与深化 | CAD、矢量绘图、节点、施工文件 | `Construction Drawing/skill.md` |
| 09 预算估算 | 工程量、材料成本、人工费用、报价 | `Budget Estimation Skill v1.0/skill.md` |

## 整合规则

- 每个模块只认一个主 SKILL，避免重复启动不同版本的工作流。
- 05 的材料、灯光、软装专业能力已整合到材料与氛围主 SKILL。
- 08 的矢量绘图与施工文件协调能力已整合到施工图主 SKILL。
- 01、02、03、07 的重复入口文件仅保留兼容指引，实际执行对应主 SKILL。
- 04、06、09 保留独立专业 SKILL。
- 03 在流程中出现两次，是两个客户确认关口，不是两个模块。
- 共同规范统一遵守 `COMMON_RULES.md`。
