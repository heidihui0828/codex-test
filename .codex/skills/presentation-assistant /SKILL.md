# 03 设计汇报与视频制作

## 模块定位

03 是统一的设计传播与客户确认模块，在固定工作流程中出现两次：

**01 → 02 → 03（第一次）→ 04 → 05 → 06 → 07 → 03（第二次）→ 08 → 09**

不得把两次 03 理解为两个模块，也不得新增模块。

## 第一次：概念方案汇报与确认

**输入：** 02 概念设计成果。

**工作：**
- 梳理设计定位、概念策略、设计故事和初步方案；
- 策划汇报逻辑与页面顺序；
- 完成提案册、PPT或PDF版面；
- 需要时制作概念阶段短视频；
- 汇总客户意见、修改项和确认状态。

**输出：** 概念汇报文件、版本记录、客户意见及明确确认记录。

**流程关口：** 未取得客户明确确认，不得进入 04；修改意见返回 02，修改后重新汇报。

## 第二次：完整设计汇报与确认

**输入：** 02、04、05、06、07 已完成并核对一致的设计成果。

**工作：**
- 整合概念、空间规划、材料氛围、景观及效果图成果；
- 统一提案册、PPT、PDF的版式与视觉语言；
- 制作完整项目视频：脚本、分镜、画面顺序、字幕、旁白建议、转场及剪辑；
- 检查视频与已确认设计成果一致；
- 汇总客户意见并取得完整方案确认。

**输出：** 完整设计汇报文件、项目展示视频、版本记录及客户确认记录。

**流程关口：** 未取得客户明确确认，不得进入 08；修改意见返回对应设计模块，完成修改后重新汇报。

## 版面设计规范

- 建立统一页面比例、网格、边距、对齐及留白规则；
- 统一字体、字号、色彩、图片比例、图注和信息层级；
- 根据内容安排平面图、分析图、材料板、效果图及细节图；
- 页面目录、章节组织和视觉展示归 03；
- 施工图的线型、图层、尺寸标注及技术制图标准归 08。

## 视频职责边界

- **03 负责：** 视频主题、叙事、脚本、分镜、版面、字幕、画面编排、剪辑节奏、视觉统一和最终汇报交付。
- **07 负责：** 效果图、空间场景、材质光影表现及空间动画素材。
- 视频必须忠实于已完成的设计成果，不得为了镜头效果擅自改变空间几何、布局、材料或设计决策。
- 如果当前工具无法直接输出视频成片，应明确说明，并交付可执行的脚本、分镜、素材清单和剪辑说明，不得虚报成片。

## 客户确认记录

每次汇报均记录：阶段、文件版本、提交日期、客户意见、修改项、确认状态及确认日期。状态仅使用：待确认、修改中、已确认。

客户未明确确认不得推进。已确认内容不得被后续模块擅自修改；如确需变更，返回相关模块并重新履行受影响的确认流程。

## 禁止事项

- 不得自行创造或改变设计决策；
- 不得把未确认成果包装成最终方案；
- 不得遗漏客户意见和版本记录；
- 不得用版面或视频处理改变原始图纸及已确认设计；
- 不得将 03 的两次汇报合并成一次或跳过任一确认关口。

## 共同规则

执行前读取并遵守 `.codex/skills/COMMON_RULES.md`。原始 CAD、DXF、SU、PDF底图及用户明确限制优先。
